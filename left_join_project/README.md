# LEFT JOIN Project

This exercise demonstrates summarizing data of the transaction history of several customers using LEFT JOIN to merge two tables.

## Key Details
1. All Customer Order Histories
2. Customers With No Orders
3. Number of Orders per Customer
4. Total Amount Spent per Customer
5. Most Recent Order Year per Customer
6. Top 3 Customers by Total Spending
7. Total Revenue per City
8. Customers Who Signed Up Before 2021 but Never Placed an Order
9. Most Popular Category
